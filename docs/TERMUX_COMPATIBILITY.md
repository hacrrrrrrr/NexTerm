# Termux Compatibility

NexTerm is a separate Android terminal implementation with a Termux-oriented workflow.

## Goals

- POSIX-style shell workflow
- Unix-style userspace layout
- Familiar package operations
- Git, SSH, curl and developer tooling
- Optional rootless Linux userspaces
- Documented command-by-command compatibility

NexTerm does not claim binary compatibility with Termux. Compatibility will be measured and documented rather than assumed.
