# NexTerm API Studio

A zero-backend API generator designed for GitHub Pages.

Features:
- OpenAPI 3.0.3 generation
- Endpoint designer
- Downloadable openapi.yaml
- Clipboard copy
- Mobile-friendly UI
- Runs entirely in the browser

No API keys or server are required for the generator itself.

## GitHub Pages

GitHub Pages can host static HTML/CSS/JavaScript directly from a repository. Enable Pages for the repository and publish the directory containing this site.

See GitHub Pages documentation:
https://docs.github.com/en/pages/getting-started-with-github-pages
